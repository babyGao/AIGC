# 工艺依据

工序里的数字都有出处；与口述有出入的只有一处（冰冻）。**有两个数是估算或未获官方确认的**，见表中标 ⚠ 的两行。

| 环节 | 片中口径 | 与口述的出入 |
|---|---|---|
| 磨粉前处理 | 地黄、麦冬等黏药 60℃ 左右烘透、冷透变脆，再与群药一同碾（行话叫"串料"） | 口述记的是"冰冻"。查到的通行做法是烘干后冷透；冷冻没找到可靠出处，未采用 |
| 细度 | 过一百目细罗 | 无 |
| 炼蜜 | 嫩蜜 105–115℃、中蜜 116–118℃、老蜜 119℃ 以上；中蜜的标志是均匀细密、有光泽的"鱼眼泡"，捻之粘手不拉丝 | 与"绵密泡沫为临界点、色在浅褐深褐之间"一致 |
| 和药 | 离火稍凉再下粉（方中有阿胶和芳香药，怕烫）；蜜粉约各半 | 一致 |
| 过油 | 麻油与蜂蜡熔合，薄薄一层，防粘、润面、利保存 | 一致 |
| 大小 ⚠ | 古方"如弹子大"；片中按鱼丸大小**估算**为径约 2.6 厘米、约 12 克 | 通行的大蜜丸每丸 3–9 克，12 克偏大；若要严谨可改成 9 克 |
| 三丸抵一瓶 ⚠ | **只按重量**：12 克 ×3 ≈ 浓缩丸 200 粒（每 8 粒 1.44 克）≈ 36 克 | 片中写明"论分量"，不比药效。"每 8 粒 1.44 克"是常见说明书规格，这次没查到官方页面直接确认，发布前请对一下手边的药瓶 |

## 两点提醒

- 含水量各家说法不一（中蜜有 14–16% 与 10–13% 两说），片中没有用。
- 古方原文是"空腹酒服一丸"。片中只把它当铭文引用，收束语改成"空腹嚼开一丸"，并在片尾注明"不作用药建议"。

- 炼蜜三档与制丸润滑剂：A+医学百科"蜜丸"条、百度百科"炼蜜"条及多篇蜜丸手工制法文章（互相印证）
