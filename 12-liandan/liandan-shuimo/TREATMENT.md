# 一颗丹的炼成 · 水墨版 · 导演阐述（第二版）

横屏 1920×1080，24 帧/秒，60 秒。男声旁白（微软 Yunyang）、古琴配乐、拟音。第二版按分镜意见改了四处：加低饱和淡彩、药瓶照实物复刻、丸子散落不排队、五行改为水墨太极并补足古籍原文。

## 0. 与原片的对应

叙事骨架原样保留：钩子 → ①原料溯源 → ②工艺六步 → ③五行 → ④所宜 → 收束。

| 原片 | 水墨版 |
|---|---|
| 钩子：市售小丸对一丸 | 照实物复刻的药瓶、药盒、一碟小丸；一滴浓墨落成一丸，绕丸写出"丹"字（丸即字里那一点） |
| 三路药材倾倒 | 三只青花罐倾倒，廿一味各落成一小堆，堆下写药名与产地，方中要点（君·三十分、廿八分、百枚为膏）用朱；阳枯笔淡赭，落定后几缕淡墨上行；阴湿墨深褐，贴纸洇开一层墨；和圆笔，枣子一点枣红 |
| 磨粉、炼蜜 | 铁碾飞白成粉（淡赭）；蜜由淡黄熬到浅褐，切蜜面特写看鱼眼泡 |
| 橙色剪纸手 | 写意墨手（袖子一点花青）拍三下，药团由蜜黄转深褐 |
| 成丸 | 丸子散落在圆竹匾上，油笔扫过逐颗转亮 |
| 橙铜丹炉 | 浓墨重鼎，回纹留白，腹中一点朱红炉火 |
| 五行圆盘 | 水墨太极：土为中枢，淡墨自左升（木火），浓墨自右降（金水），阳中那一点黑就是丹 |
| 所宜 | 百丸排成长路一路走到雪晨，服丸人腹中一点暖 |

**颜色**：墨色为主，淡彩只点在药材、蜜、药团、丸、青花罐和五行五色上；朱红只给炉火、印章、药签和腹中那点暖。

## 2. 一句话与弧线

市面一瓶二百粒，古人一次只一丸——长卷展开，看廿一味药怎样变成一枚乌亮的丹，再看这一丸里藏着怎样一圈气。
起：一碟小丸对一滴浓墨。转：丹出炉后钻进丸里，它是一幅"左升右降、土居中枢"的太极。合：回到卷首，三丸抵一瓶；好药不怕慢。

## 5. 五行的依据

| 行 | 方位天干 | 五色 | 片中原文（《金匮悬解》） |
|---|---|---|---|
| 木 | 东方甲乙 | 青 | 肝主生发；归胶滋肝而养血，地芍润木而清风，芎桂疏郁而升陷，以助乙木之生发 |
| 火 | 南方丙丁 | 赤 | 柴胡白蔹，泻相火而疏甲木 |
| 土 | 中央戊己 | 黄 | 土位在中，是为升降金木之枢；大枣补己土之精，人参补戊土之气 |
| 金 | 西方庚辛 | 白 | 肺主收敛；薯蓣敛肺而保精，麦冬清金而宁神，桔杏破壅而降逆，以助辛金之收敛 |
| 水 | 北方壬癸 | 黑 | 元阳在肾（《辑义》引魏荔彤） |

"左升右降、土枢四象"是黄元御"一气周流"的讲法；把太极的阴阳二鱼对应升降是片中的图解处理。"火"一行与上一版相同，是因"泻相火"一语归入火位，原文未单立。引文为一眼读完有删节，未改原意。

## 6. 配乐与声音

D 宫五声，五行段一行一音：宫 D（土）、角 F#（木）、徵 A（火）、商 E（金）、羽 B（水），太极旋紧时五音由慢到快扫弦，落回宫音。

| 段 | 音乐 | 拟音与环境 |
|---|---|---|
