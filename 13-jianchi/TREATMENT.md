# 坚持 · 导演阐述（航海王漫画版）

横屏 1920×1080，30 帧/秒，216.29 秒。时间轴以用户音频为准（`data/cues.json`），文案不改；正式配音由用户自己做，成片里带的原音轨只用来对时间。

## 1. 一句话

一条没有尽头的河，所有人都在吼、在哭、在疯，只有一个人面无表情地一步一步往前走，直到他的坚持在体内亮成一只仙蛊。

## 2. 90% 还原 + 10% 发挥

- **90%：形象来自素材。** 人物不重新设计，直接取同人视频里已经成形的画面，逐帧重绘成黑白漫画。方源的脸（长发遮眼、细长眼、薄唇紧抿、白衣大袖黑腰带）、雪胡老祖（白发白须、皱纹、毛领）、毛里球（紫貂身形、紫晶眼、獠牙，用蓝兔Ai 的版本，最贴原文“像貂”）、赵怜云（老妪、额饰）、白凝冰、黑楼兰、群仙，都保持素材里的五官和比例，不变形。
- **10%：动势和情绪是加的。** 运镜、冲击帧、集中线、拟声字、音浪、黑色闪电、光爆、分格、回忆段的换纸——这些是从航海王和一拳超人学来的“冲击力”，叠在素材之上。

## 3. 画风：从用户给的航海王四页里抽出来的规则

| 规则 | 片中做法 |
|---|---|
| 黑白、墨线干脆 | 每帧做 XDoG 墨线（细节线 + 外轮廓粗线），明度分成 实黑 / 密网点 / 疏网点 / 白 四层，45° 网点固定在画面上（像印刷） |
| 大面积实黑 | 头发、阴影直接压成实黑块，开闭运算去掉碎边 |
| 集中线 | 吼、急推、冲击时出现；一拍二重绘（线在“抖”） |
| 一拳超人式冲击帧 | 人物抠出来，背景换成白底集中线、外轮廓加粗黑边（“柳贯一！”“天意！”“为什么是他！”“目光如磐石”“坚持仙蛊”） |
| 巨大拟声字 | 马善政毛笔字，黑字白粗边，弹入 + 震动：唰、吼、嗷、轰、啪、嗡、杀、哗、咚、铮、成 |
| 音浪 | 从嘴/光源扩出的黑色锯齿环（雪胡仰天咆哮、毛里球比雪胡更高的音量） |
| 霸王色黑电 | 坚持仙蛊成形前，方源周身劈出黑芯白边的闪电 |
| 斜切分格 | “四面楚歌”五格围住方源；“神情扭曲/痛苦万分”“疯狂/哭泣”；“责任·仇恨·精彩·爱情”四格逐格拍下，旧格变灰 |
| 阴云竖线 | 失神、震惊（碧晨天、威灵仰失神落魄；“这怎么可能？”） |
| 脸不变形 | 夸张只给效果和镜头，五官一律保持素材原样 |

**颜色是事件**：全片黑白，只有三处带色——毛里球的紫（眼、紫电）、九转爱情仙蛊的粉紫光、回忆段的暖黄纸褐墨。

## 4. 运镜：诺兰式，九种

| 运镜 | 用在哪 |
|---|---|
| 慢推（dolly in） | 方源的独白、近景特写，越推越近 |
| 拉出揭示（IMAX 极远景） | 开场从一只脚拉到无尽长河，人只有几十像素 |
| 急推 + 径向模糊 | 雪胡指人、爱情仙蛊、天意、杀、目光如磐石、炼成 |
| 跳焦 | 碧晨天“马鸿运……”——画面突然推近一格 |
| 摇（tilt / crane） | 雪胡仰天、方源仰头、赵怜云被光托出河外 |
| 横移（truck） | 夹着尸体的方源、被冲出河外的人 |
| 荷兰角（dutch） | 群仙逼近、叫嚣 |
| 手持晃动 + 冲击震 | 所有吼叫、爆发 |
| 希区柯克变焦（vertigo） | “方源强忍心中震动”——人不动，背景纵深被拉开 |

外加：全片 2.39:1 遮幅，**204.68 秒光芒骤放时遮幅撑开到满画幅**（《奥本海默》《星际穿越》的 IMAX 撑开）；“先光后声”——光先炸，0.45 秒后冲击波和“轰”才到；138–142 秒音乐骤降处只留他和水声，不加任何效果。

## 5. 结构

| 段 | 时间 | 画面 |
|---|---|---|
| 前奏 | 0–7.2 | 一只脚踩进水里 → 拉到极远景，长河没有尽头 |
| 暴怒 | 7.2–36.6 | 雪胡老祖（指人、咆哮、音浪）→ 鸿运消散成光点 → 碧晨天失神 → 毛里球（龇牙、紫电、音浪） |
| 变故 | 36.6–57.8 | 方源的眼 → 赵怜云 → 希区柯克变焦 → 手刀“啪” → 九转爱情仙蛊（粉紫光）把赵怜云托出河外 |
| 绝境 | 57.8–77 | 天意（冲击帧）→ 仰头 → 四面楚歌五格 → 群仙逼近、荷兰角 → “杀” |
| 无尽 | 78–100.6 | 极远景的河、板绘黑河长卷 → 一步再一步（咚、涟漪）→ 毛里球的吼字越来越小 |
| 追问 | 100.9–138.2 | 群仙的脸 → 斜切分格（扭曲/痛苦/疯狂/哭泣）→ 方源始终不变 → 被冲出河外的人 → “为什么是他！” |
| 静场 | 138.2–142.1 | 只剩他和水 |
| 各自的坚持 | 142.1–159 | 四格逐格拍下：责任、仇恨、精彩（白凝冰）、爱情（赵怜云） |
| 回答 | 160.2–204 | 独白：每句先回忆（暖黄纸）后现在（黑白），“目光如磐石”冲击帧，“这就是我”三连闪，“方源的——坚持！”黑电 |
| 炼成 | 204.7–216.3 | 光芒骤放、遮幅撑开、音浪 → 光中的方源（集中线）→ 光中的脸“成” → 片名“坚持” |

## 6. 素材取舍

- 主线用松楠剧制（BV1zLNd6ME7B）：方源白衣、灰调逆流河，剧情几乎逐句对应。
- 毛里球用蓝兔Ai（BV1PGp26cExn）的紫貂，不用松楠的紫狼（原文“像貂”）。雪胡指人、方源夹尸、仰头、光中的脸也取蓝兔。
- 板绘黑河长卷取轮回画室（BV19pC9BEE4j）。
- 雕真人的 2D 版（BV1vYZtB2EpA）画风太幼，只作参考不入片。
- 原视频烧录的字幕和水印：先修补（亮色细笔画 inpaint），再被 2.39:1 遮幅盖住。

## 7. 还没把握的地方

- 来源是 1280×720 / 1280×544 的视频，放大到 1080p 后远景细节偏软，漫画化之后部分远景是成片的网点块。
- 两部同人里方源的脸略有差别（松楠更冷、蓝兔更柔）；主线都用松楠，蓝兔的方源只出现在夹尸、仰头、天意、炼成几镜。
- 雪胡“双目赤红”没有上红色（素材里眼睛太小，单独抠会抖）。
