# 新版四风格：全片小样

每种风格把 K1–K11 十一个关键镜头按片中顺序排成一张（诺兰的调度 + 航海王的打斗画风；同一份角色母版、同一套调度，只换材料）。

- `全片小样_woodcut.jpg` 木刻版画
- `全片小样_puppet.jpg` 皮影戏
- `全片小样_ink.jpg` 中国水墨
- `全片小样_spy.jpg` 60s 间谍片头

单个镜头可以重渲：`film/?lab=shot&shot=K5&style=ink`（K1 是 `?lab=k1&style=…`）。镜头的元素描述在 `film/shared/shots.js`，各风格的画法在 `film/<风格>/shots.js`。
