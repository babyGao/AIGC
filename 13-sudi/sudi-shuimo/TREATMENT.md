## 0. 歌曲读解：我们要讲的到底是什么

参考资料里读者的共识，加上我自己的读法：

1. **歌词最贴近萧峰与阿朱。** 恩怨各一半（恩师、养父母、生父、少林、雁门关）；灯笼血红染、寻仇已太晚（赶到时人已死）；天上星河转（阿朱金锁片上的「天上星，亮晶晶，永灿烂，长安宁」）；长安（不是西安，是「长久安宁」）；绝笔；借你的孤单今生难还（误杀阿朱后终身不再爱人）。
2. **但歌不拘泥于原著。** 主歌一更像所有江湖爱侣的总括，主歌二「孤岛、雪雨、海上星、灵柩、秘密」是许嵩自己的意象。
3. **整首歌的题眼是一个反转：宿敌是谁？** 一位读者写道：「原来，你才是我命中的宿敌呀。」万敌不侵的人，只败给一个人。命运把相爱的人放到了刀的两端。宿敌是命，也是她。

所以 MV 的核心命题：**一个万敌不侵的人，一生只输给一个人。命运让她成了他的宿敌，他亲手失去了她，从此借她的孤单，用一生去还。**

我不点名任何原著人物，画面只用写意人形（男、女、门童），让熟悉原著的人一眼认出杏子林、青石桥、雁门关、金锁片、塞外牛羊之约，不熟悉的人也能看懂一个完整的爱情悲剧。

## 1. Claude 小宠物：朱砂小兽（Clawd）

水墨风格只允许**一种朱红**：印章 + 故事里一个很小的强调物。这个强调物就是 Clawd。

- 「朱」字本身就是朱砂红；她的小宠物是整幅画里唯一的颜色。远景里一点红，就能找到她在哪里。
- 她死后，Clawd 跟着他走。**红色从她身边移到他身边**：不用一句台词就说明「她还在陪着他」。这正是「摘取一颗海上星，陪我终夜不孤寂」。
- Clawd 也是全片的**见证者**。三次副歌里的「月下门童」：第一次是一个真的小门童；第二次门童换成 Clawd，坐在雁门关下等一个不会回来的人；第三次门后亮起光，他们回来接它。
- 结尾 Clawd 跳到画角，「啪」地落下，留下一方朱红白文印「长安」：整幅画由这只小兽钤印收尾。印章就是 Clawd 的形状（方块），红色从头到尾只有这一种。
- 造型：Claude Code 终端里那只方块小兽（方身、两只竖眼、两侧小短手、四条小短腿），用水墨写意画法重画：一团朱砂没骨块面 + 焦墨两点竖眼 + 几笔短腿。它会眨眼、歪头、抖雪、举手、跑跳，动作用 12 fps 一拍二，压扁拉伸有预备与回弹。

## 2. 三个候选结构，以及选择

| 方案 | 结构 | 优点 | 问题 |
|---|---|---|---|
| A. 一幅长卷 | 全片一个从右到左的长卷横移，四段歌各占一段画卷，结尾拉远看到整卷 | 一镜到底，壮观 | 歌曲 4 分 23 秒，一镜到底会很平；三次副歌只能横移到新地方，没法「回到旧构图看出变化」；与 demo 的长卷收尾重复 |
| B. 四季轮回 | 春遇、夏恩怨、秋诀别、冬孤岛，季节就是叙事 | 视觉变化清楚 | 季节压过了人物；歌词里的灯笼、门童、星河、绝笔会被季节景观稀释 |
| **C. 闪前 + 三次副歌递进（选用）** | 开头三秒闪回「青石桥雷雨一掌」作钩子 → 主歌一相遇 → 副歌一恩怨 → 间奏把开头那一掌完整演完 → 主歌二孤岛 → 副歌二赴雁门关 → 一小节静默 → 副歌三星河重逢 → 尾奏 Clawd 钤印 | 三次相同的副歌歌词，用**同一组构图**（圆、灯笼、门童与月、星河命盘、绝笔、过门）讲三层不同的意思：恩怨 → 失去 → 释然。前三秒有悬念，间奏兑现悬念 | 场景多，要严格控制每段的转场语法 |

选 C。理由：MV 最怕三遍副歌三遍同样的画面。C 让每一句副歌都有一个固定「母题构图」，第二、三次回到这个构图时，里面的人和意义变了（STYLE.md §6「回到先前的构图：押韵显示变化」）。

## 3. Logline 与弧线

**Logline**：雷雨夜的青石桥上，万敌不侵的他一掌击中了那个唯一能打败他的人；从此他带着她留下的朱砂小兽，走完借来的孤单。

- 开场（0–22.6 s）：闪前一掌 → 片名 → 从天上星河竖摇到人间（世界和所有母题一次交代）
- 起（主歌一）：杏花林相遇，刀剑光影里他无敌，却被一片花瓣「打败」
- 承（副歌一）：恩怨一半、灯笼染血、门童叹月、星河定盘、她写下绝笔、乔装赴约
- 转（间奏）：青石桥。静默，一掌化龙，斗笠飞落，是她
- 合一（主歌二）：孤岛雪雨，Clawd 捞起海上星，灵柩、金锁的秘密，染指江湖
- 合二（副歌二）：他站在两军之间（他本就一半是这边、一半是那边），月下门童换成 Clawd，塞外牛羊的梦，他的绝笔，折箭
- 静默（1 小节）：空崖、断箭、Clawd
- 升华（副歌三）：Clawd 在雪里绕出一个圈；万盏天灯升起；门后亮起光；桥上倒放，龙回掌心，她站起来；两人走进星河
- 尾（尾奏）：画面按笔序倒着「蒸发」，只剩星河和 Clawd；Clawd 一跳落成印章「长安」；题跋「天上星 亮晶晶 永灿烂 长安宁」

## 5. 世界与造型

- **他**：宽肩大汉，乱发束起，宽袍外罩毛边大氅（他身世一半在塞外），赤手不带兵器。淡墨身体一团 + 两笔饱墨，四肢焦墨。
- **她**：纤长，长发及腰，水袖。身上有一枚小金锁（淡墨小方块，特写时刻字）。
- **门童**：小孩，执扫帚，只在副歌一出现。
- **Clawd**：朱砂红（唯一的颜色），见上。
- **母题物**：杏花（春）、圆相（恩怨）、灯笼（家）、月（门童）、星河命盘（命）、绝笔（信）、拱桥（宿命之地）、金锁与星（她）、断箭（他的终局）、印章「长安」。

## 6. 分镜表（时间 = 歌曲时间，秒）

景别：远=大远景/远景，全=全景，中=中景，近=近景，特=特写。转场一律用水墨本体语法：墨晕（下一场在扩散的墨滴里长出来）、雾带横移、雨水冲刷、形状匹配（圆 → 月 → 命盘；花瓣 → 星），不用叠化、不用划像。

## 7. 节拍表 / Cue map

- 速度 96.9 BPM，4/4，一小节 2.4769 s；第 0 小节起点 0.282 s。段落小节号：前奏 0–9，主歌一 9–25，副歌一 25–41，间奏 41–50，主歌二 50–66，副歌二 66–82，停顿 82–83，副歌三 83–99，尾奏 99–106.2。
- 大的画面事件都落在重拍或歌词关键字上（字级时间）：圆相闭合落在「揽」，灯笼渗墨从「染」开始，门童叹气在「叹」，命盘停在「盘」，墨痕干在「干」，雷声在「犯」，掌出龙在间奏第 44 小节第 1 拍（静默之后），印章落在尾奏第 103 小节第 1 拍。
- 转场点一律放在乐句尾的长音上（每句最后一个字时值 1–2 s），不在歌词中间切。
- 节奏变化：前奏慢（竖摇 13 s 一个镜头）→ 主歌一中速（5 s 一个镜头）→ 副歌一快（2.5 s 一个变化点）→ 间奏先极慢再极快（静止 3 s，出掌 0.25 s）→ 主歌二慢（雪、孤岛，留白最多）→ 副歌二快 → 一小节静默 → 副歌三宽（镜头长，向上）→ 尾奏极慢。

## 9. 歌词字幕（卡拉 OK 细体）

- 字体：思源宋体 Light（Noto Serif SC 300，OFL），细、清、像题跋；只取全片用到的字做子集。
- 布局：经典 KTV 双行错落。上句靠左、下句靠右，两句同时以淡墨出现，演唱时逐字「着墨」：淡墨底 → 焦墨（纸面亮的镜头）或 淡纸色 → 亮纸白（夜里的镜头）。走字是每个字内部平滑推进的软边，跟着逐字时间走。
- 每行开头一个小朱红方块（风格要求）。字幕出现提前 ≥0.6 s，句末保持 ≥0.6 s，然后像墨迹一样「干」掉（不硬切）。
- 位置跟随每个镜头的留白区，永远不压主体；不跟随世界相机（屏幕空间）。
- 字号 54 px，字距 0.16 em；在暗场用纸色字 + 很淡的墨晕衬底保证可读。
- 片名「宿敌」用马善政毛笔字作骨架逐笔描写；题跋同理。
