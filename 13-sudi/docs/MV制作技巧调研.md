## 一、MV制作技巧

### 1.1 先画“歌曲结构图”，再给每段分配画面职责
- 动手前先标出前奏、主歌、导歌、副歌、间奏/桥段、尾奏，并给每段写一句“这段画面的任务”。参考分工如下：
  - 前奏：建立世界与氛围
  - 主歌1：交代人物和他的困境、视角
  - 导歌：加压，提高运动、景别和对比
  - 副歌：视觉锚点，即最可辨认的那个形象
  - 主歌2：换场景，推进故事
  - 桥段/间奏：重置，转向内心或反转
  - 末段副歌：兑现，规模更大、情绪更重
  - 尾奏：用故事、母题或氛围收束，不要习惯性再接一段演唱
- 规划顺序：先排结构，再定每段视觉内容，最后才按节拍组装。只认 BPM 不认段落的卡点片，看起来会很机械。
- 自检失败模式：①画面持续演唱却没有新信息；②故事镜头删掉也不影响剧情；③随手插入的“美图”打断连续性；④副歌没有视觉锚点；⑤桥段和副歌没有反差。
- 起步配比可以用“表演 40% / 故事 40% / 氛围空镜 20%”。没有歌手出镜的动画 MV，可把“表演”换成“主角或宠物的标志性动作”。

### 1.2 剪辑点与节拍：卡点是底层，疏密才是表达
- 不要每一拍都切。可以把重拍当网格，在网格上安排疏密，形成铺垫、加速、释放、停顿、揭示这几种层次。
- 剪辑密度可以随能量曲线走，以下为厂商经验值：
  - 前奏：4–8 小节切一刀，用长镜头、留白和慢推
  - 主歌：2–4 小节切一刀，贴着歌词断句
  - 导歌：1–2 小节切一刀，逐渐加密
  - 副歌：每小节或每半小节切一刀
  - 桥段：故意打破前面的节奏
  - 尾奏：落在一个长镜头上
- 转场时长参考：高能段落用约 0.3 秒的快切，低能段落用约 1.5 秒的慢溶。
- 切点最好同时对上音频峰值和画面运动峰值（挥剑到顶、落笔、回头），这样卡点显得有机，不像机器。
- 打磨精力集中在拐点上：前奏到主歌、主歌到副歌、副歌到桥段。中间稳定段落用默认节奏就可以。
- 卡点越准，镜头间色调、主体、运动方向不统一就越扎眼。卡点之前先统一调色和运动方向。

### 1.3 副歌重复时，画面要递进
- 原则是同一个视觉锚点加不同状态。第二遍副歌比第一遍更密、景别更近；末段副歌把锚点“放大或停得更久”，并带上前面主歌积累的后果。
- 递进可以从五个方向做，每遍副歌至少换两个：
  - 景别：远 → 中 → 近/特写
  - 运动：固定 → 慢推 → 环绕/升格
  - 色彩：素墨 → 墨中点一抹朱红 → 朱红扩散
  - 母题状态：完整 → 破损 → 转化
  - 构图权重：人物从小变大，或反过来从大变小、只剩背影〔经验〕
- 歌词相同的副歌可以换叙事视角：第一遍从主角看出去，第二遍从宠物或对手看，第三遍用上帝视角远观〔经验，借鉴《英雄》“同一事件、不同版本”的结构〕。

### 1.4 视觉母题（motif）与呼应
- 一支 3 分钟的 MV 用一个主母题，最多再加一个副母题。三个以上就等于没有母题。
- 主母题出现 4–6 次，状态至少变一次。六次出现都一模一样，母题就成了贴纸，讲不出故事。
- 选母题的方法：圈出歌词里的具体名词，选情绪转折句里的那个。没有合适的名词时，可以用颜色母题（灰调里一个饱和的强调色），或者构图母题（反复出现的同一种取景）。
- 放置位置：
  - 前奏：特写首次亮相
  - 主歌1：退到背景
  - 副歌1：回到画面中心
  - 桥段：改变状态
  - 末段副歌：以变化后的状态强势重现
  - 尾奏：呼应开头，母题定格在最终状态
- AIGC 生成时，每一段的提示词都要用同一个母题短语，比如固定写“红灯笼”，不要轮换同义词，否则生成出来的形象会漂移。
- 发布前做静音测试：关掉声音看一遍，故事仍然完整才算合格。

### 1.5 转场：拒绝生硬，用有动机的连接
- 图形匹配（graphic match）：前后两个镜头在形状、颜色、构图或运动上对位。经典例子有《2001太空漫游》骨头接卫星、《阿拉伯的劳伦斯》火柴接日出。
- 动作匹配：在动作进行到一半时切，比如挥袖、旋身、拔剑到一半，观众的视线会跟着动作越过剪辑点。
- 声音桥：用 J-cut 让下一场的声音先进来，或用 L-cut 让上一场的声音延续过去。风声、琴声、雨声都很适合用来跨场景。
- 前期就要设计好这些匹配，靠后期找很难：先决定两场之间过了多少时间（时间短就硬切，时间长就溶接），再指定一个贯穿多个镜头的实物，并在道具、服装、光线里预埋相同的形状或颜色。
- 水墨溶解或墨晕转场的做法：拿一段墨迹扩散或笔触铺满画面的素材，最好是由黑到白，做亮度遮罩或轨道遮罩，用它揭示下一个画面。也可以模拟墨滴入水来显影。
- 〔经验〕墨晕转场必须有画面里的“起因”，比如落下一滴墨、扫过一道衣袖、溅出一片水花、吹过一阵风，并让墨晕的形状接上下一个镜头的主体轮廓。全片不加区别地套用墨晕，就和 PPT 转场差不多。
- 古风 MV 的一种高级手法是“意象联想”。《风从千年来》MV 用中国结的形状联想到立交桥，再用一组不同物件的“中国红”快切出颜色串联。

### 1.6 高潮的视觉峰值，以及静默和留白
- 末段副歌就是全片最大的视觉兑现，剪辑最密的段落、最大的景别反差都留到这里用。
- 峰值之前先收一下：在高潮前放一拍静默、一个长停顿或一个空镜，靠对比让注意力回来。整段都满的话，高潮反而失效。
- 静默要少用，并且要和角色当下的感受绑在一起（斯科塞斯的观点）。真正的静默多出现在主观视角或梦境里。
- 反向用法：情绪最高点不一定要推特写，也可以退到大远景，比如《卧虎藏龙》李慕白临终那场。从一组近景切到一个几乎全黑、只有俞秀莲背上一束光的远景，把私密感留给角色。
- 留白就是“计白当黑”。水墨画面里大面积空白本身就是构图的一部分，人物和母题只占画面的 1/5 到 1/3〔经验〕。

### 1.7 开头前三秒的钩子
- 第一帧就要有视觉张力，比如运动、焦点或悬念。静止的平铺画面在信息流里很容易被划走。
- 五类钩子，难度由低到高：①第 0 秒画面就在动（推、移、元素入画）；②冷开场，先给高潮或副歌最强的一帧；③文字钩子，把最抓人的一句歌词放到开头；④第一刀落在第一个重拍上；⑤主体放在画面中上方的“黄金区”。
- 推荐组合是“首帧运动 + 文字钩子”。同一支片子里钩子只用一到两种，用多了会乱。
- 三秒内要让观众知道“这片讲什么”。前奏很长的歌，不要用静止标题卡硬撑过去。
- 竖屏剪辑版可以把最强的副歌前置，开头最密，然后回落。横屏完整版可以保留慢开场，但首帧仍然要有运动。

### 1.8 KTV 逐字染色歌词：排版与可读性
- 每行字数：Netflix 简中规范是每行最多 16 字，最多两行，换行呈“上短下长”。竖屏每行 8–10 字为宜。
- 阅读速度：成人内容不超过 9 字/秒，儿童内容不超过 7 字/秒。
- 停留时间：单条最短 5/6 秒（24fps 下 20 帧），最长 7 秒。也有教程建议最短 1 秒、最长 6 秒，并在语音结束后多留约 0.5 秒。
- 字号：取画面高度的 1/20 到 1/10，1080p 下约 54–108px。BBC 对高清字幕的最小高度要求是 44px。字号按分辨率定，不要凭自己屏幕上的观感。
- 字体：花哨字体缩小后识别度会掉。正文用楷体、宋体这类骨架清晰的字，书法体、草书只用在片名或单字特写上。
- 描边与对比：白字配黑描边，或加一层半透明暗底，背景越花描边越重。可以用柔和的外发光代替重投影。
- 标点：歌词不用逗号和句号，用空格代替，只保留问号和叹号。
- 位置：全片固定在同一个区域，不要上下跳。避开人脸、嘴部和画面下三分之一里的重要动作。竖屏版要避开底部 20% 和右侧 15% 的界面遮挡区。横屏可参照广电“字幕安全框”，约为画面中央 90%〔行业惯例，本次未检索核实〕。
- 逐字时间：每个字的染色应略早于人声起音，或正好对齐。最常见的毛病是染色滞后。ASS 格式里时长为 0 的 `\k0` 标签会导致渲染静默失败，要提前清理。
- 提前出现：长间隔（前奏、间奏）之后的第一句，用 3–4 拍的倒计时圆点提示，片头标题卡默认停留约 3 秒。两句紧挨着的地方，用双行交替（上行左对齐、下行右对齐，唱完一行就换成后面的句子），保证下一句已经提前显示〔KTV 行业惯例〕。
- 可读性前提：歌词区域背后的画面要简洁，留出空白，少放细碎细节。

### 1.9 宠物或吉祥物角色在叙事中的作用
- 外化内心：孤独的主角有了可以“说话”的对象。无台词的 MV 里，主角对宠物的一个动作就能交代他的情绪和性格，因为人怎么对待动物，最能看出这个人。
- 情绪镜子：动物传达情绪主要靠肢体，比如耳朵、尾巴、炸毛、蜷缩，脸部表情用得少。设计时要给宠物一套固定的肢体词汇。
- 观众代入：可以设计成观众视角的替身。“宠物 POV”镜头低机位，看人看世界，很适合主歌的叙事。
- 母题载体：宠物可以兼任母题，比如铃铛、毛色、某个固定动作，随剧情改变状态，承担 1.4 节说的状态变化。
- 风险：宠物如果承担喜剧插科打诨，会泄掉紧张感。情绪高点让宠物安静下来，或者让它反应在前、主角反应在后。
- 治愈系设计：造型温暖、柔和，可以略带哀伤。在水墨里用“似与不似之间”的写意笔触，不必画得很写实（参照《小蝌蚪找妈妈》的齐白石笔意）。

## 二、导演创作核心要点

### 2.1 叙事弧线
- MV 的弧线用“一个任务、一个转折、一个代价”就够了。《牧笛》的“失牛、找牛、得牛”就是最小的三幕结构。
- 主歌建立“想要什么”，副歌把渴望放大，桥段或间奏放“转折或代价”，末段副歌兑现，尾奏留下余韵。
- 间奏常常就是 MV 的核心：歌词停下来，正好让画面独立讲完歌曲没讲完的东西（《风从千年来》导演朱秋玥的经验）。

### 2.2 视角（POV）
- 每一段都要回答“这是谁在看”。《刺客聂隐娘》把“刺客在看”作为景别和镜头变化的依据，用俯拍、远观长镜头、移动镜头制造“刺客始终在场却无人察觉”的感觉，摄影机的看、刺客的看、作者的看三者合一。
- 可以借来的做法：主角的主观镜头、宠物的低机位镜头、远处“旁观者”的长焦窥视，三种视角轮换。同一句歌词换一个视角，意义就变了。

### 2.3 镜头语言：景别与运镜动机
- 每一次运镜都要有动机，由角色情绪或全片基调驱动，避免无目的的“漂浮镜头”。
- 运镜和情绪的对应：
  - 慢速：平静、沉思、浪漫
  - 快速：紧迫、惊讶、混乱
  - 慢推：张力累积，对应角色情绪膨胀
  - 拉远：孤独、渺小
- 《聂隐娘》的底色是中景、远观、水平固定机位，加深焦和长镜头，传达出“气定神闲、凝神寂照”。固定机位本身就是一种态度。

### 2.4 节奏：快慢交替与呼吸点
- 快切和长镜头交替。一串快切之后接一个停住的镜头，前面的快才有意义；给每个镜头定“轻、中、重”的权重，重镜头停得更久。
- 慢和快可以同片共存。《聂隐娘》整体极慢，但一场约 15 秒的对打里至少换了十个机位。
- 《卧虎藏龙》全片节奏“前半沉郁激烈、后半轻盈羽化”。竹林段落走“以静制动”，镜头和人物都显得轻盈飘逸，节奏变化本身就在叙事。
- 呼吸点要放在三个地方：副歌结束之后、末段副歌之前、尾奏。

### 2.5 情绪曲线与音乐的配合
- 先把歌曲画成能量曲线（4–6 段），再画一条情绪曲线叠在上面。两条线可以同向，也可以反向。比如音乐最满的地方用最安静的画面，让反差制造痛感〔经验〕。
- 音画同源：《山水情》的原画作者专门向古琴家龚一学指法，把琴音的节奏画进动作细节里。乐器演奏、落笔、挥剑这类动作要和音符对位。
- 特效服务于意境，不是为了刺激（朱秋玥）。

### 2.6 象征、留白与“show, don't tell”
- 用行为、道具、颜色、环境承载潜台词，不要用字幕去解释。契诃夫的说法是：不要写“月光很亮”，要写碎玻璃上的一点反光。
- 《聂隐娘》的“淡”：时空转换不用连接镜头，搏杀点到为止，刺客潜入只拍一阵轻风掠过，远处群鸟惊散暗示有人在林中疾驰。和精精儿交手时人影都看不见，只有群鸟惊飞、叶散枝断。可以用“结果、余波、环境反应”替代动作本身。
- 风在侯孝贤的镜头里相当于画中的“水”，是画面的“空气”。水墨 MV 里可以把风、雾、水、墨晕当作一个贯穿全片的“气”，负责连接、暗示和过渡。
- 色彩分段叙事：《英雄》不同的叙述版本用不同的主色调（红、青、绿、白、黑）。可以借来做“每段一种墨色或强调色”。
- 水墨动画的意境，并不来自水墨风格本身，而是来自四件事的协同：空间开阔、节奏有生气、引导视线的漂移式画面（游观）、时长节奏。

### 2.7 首尾呼应与代表性镜头
- 首尾配对有两种：“成长型”（同一画面，人或物已经变了）和“循环型”（回到原点）。开头的母题，结尾要以最终状态再出现一次。
- 《山水情》结尾：老琴师赠琴后渡河远去，身影融进重重山峦，风声里只剩少年的琴声，画面最后落在留白和“完”字印章上。人走了，琴声还在，这就是用留白收尾。
- 代表性镜头（signature shot）要满足三点：一个画面能概括全片主题，可以截图做封面或缩略图，在片中出现两次并且第二次已经变了。全片只设计一个，拍摄和生成的资源向它倾斜〔经验〕。

### 2.8 经典参照速查
| 作品 | 可借鉴点 |
|---|---|
| 《小蝌蚪找妈妈》(1960) | 不勾线、不平涂，分层拍摄浓淡色块来模拟宣纸晕染；齐白石笔意，“似与不似之间” |
| 《牧笛》(1963) | 李可染的人物、方济众的背景；“失牛—找牛—得牛”的极简叙事；整体更偏成人化 |
| 《山水情》(1988) | 全片无对白，古琴贯穿；风、雪、鹰、垂钓、围炉、摆渡这些意象反复出现；画家现场作画、现场拍摄后合成 |
| 《卧虎藏龙》 | 竹林是情感空间，不只是打斗布景，要求拍出水墨意境；高潮时退到大远景加大片负空间 |

## 三、落地清单：本项目（水墨古风 + 卡拉OK歌词 + 宠物角色）

由 `lyrics.json` 推出的结构如下（秒）：
- 前奏 0–22.5
- 主歌1 22.5–60.4
- 副歌1 62.3–100.5
- 间奏 100.5–124.1（约 23.6 秒）
- 主歌2 124.1–162.3
- 副歌2 163.6–201.9
- 静默缝 201.9–205.8（约 3.9 秒）
- 末段副歌 205.8–244.5
- 尾奏 244.5 至结束

歌词每句 5–7 字，最高约 3.3 字/秒；副歌里有多处前后两句时间紧挨着（间隔为 0）。

- [ ] 1. **结构表先行**：按上面的时间点建分镜表，每段写一句“画面任务”和“谁在看（POV）”。三遍副歌分别标成“锚点建立、加密、兑现”。
- [ ] 2. **定一个主母题和一个副母题**：建议主母题用歌词里的“灯笼（血红）”，作为灰墨世界里唯一的朱红强调色；副母题用“笔墨痕”或宠物的铃铛。每段提示词都用同一个固定短语。
- [ ] 3. **母题状态表**：前奏特写亮起 → 主歌退到背景 → 副歌1回到画面中心 → 间奏熄灭或破损 → 末段副歌以新状态出现（比如化成墨染的红） → 尾奏呼应首帧。全片出现 4–6 次。
- [ ] 4. **三遍副歌的递进**：在景别、运动、朱红面积、视角（主角、宠物、远观）四个方向中，每遍至少换两项。不允许直接复用前面副歌的镜头。
- [ ] 5. **剪辑密度表**：前奏 4–8 小节切一刀，主歌 2–4 小节，副歌每小节，末段副歌每半小节。只在“上行到峰值”的拐点加密，主歌保持长镜头和留白。
- [ ] 6. **前三秒**：首帧要有运动，比如一滴墨落进水里晕开成山。第一刀落在第一个重拍上。如果有竖屏切条版，把最强的副歌画面前置。
- [ ] 7. **用好 23.6 秒的间奏**：这里没有歌词，正好拿来放“转折或代价”，可以是宠物独立的一段戏、一场写意交手（只拍风、鸟、落叶、断枝，不拍刀剑碰撞），或者母题被毁。
- [ ] 8. **3.9 秒的静默缝**：在 201.9–205.8 秒做呼吸点，用一个固定空镜（留白山水，或宠物一动不动的背影），然后在末段副歌第一拍放出全片的代表性镜头。
- [ ] 9. **转场清单**：每个转场都要写明它的匹配依据（形状、动作、颜色或声音）以及画面里的起因。墨晕溶解全片不超过 4–5 次，只用在时空跳转处；同一场景之内用硬切或动作匹配。
- [ ] 10. **字幕配色要适配水墨**：水墨画面底色多是宣纸白，传统 KTV 那种白字加蓝染色会看不清。建议未唱的字用浓墨色、加约 2px 的宣纸白描边或淡晕底，唱过的字用朱砂红（和灯笼母题呼应）。上线前在手机上分别对着亮底和暗底各检查一遍。
- [ ] 11. **字幕排版**：1080p 下字号取 72–96px（画面高度的 1/15 到 1/11），字体用楷体或宋体类，不用草书；不用标点，句内停顿用空格；位置固定在下方安全区，不遮挡人脸和宠物；竖屏版避开底部 20% 和右侧 15%。
- [ ] 12. **字幕时间**：逐字染色直接用 KRC 的字级时间，每个字可以提前 0–50 毫秒〔经验〕。每句至少提前 0.8–1 秒整行显示〔经验〕，前奏和间奏之后的第一句加 3–4 拍倒计时点。副歌里间隔为 0 的连续句，用上左、下右的双行交替显示。检查不能有时长为 0 的字。
- [ ] 13. **宠物的人设和肢体词汇**：给宠物定 3–5 个固定动作，比如竖耳表示警觉、蹭手表示安慰、背对镜头蹲坐表示等待。主歌里用宠物低机位的 POV 交代世界；情绪高点让宠物保持安静，不抖机灵。
- [ ] 14. **首尾呼应和代表性镜头**：尾奏回到开头的构图，人物或宠物、灯笼换成最终状态。全片指定一个可以做封面的代表性镜头，并让它出现两次，第二次已经变化。
- [ ] 15. **验收**：静音看一遍，故事要完整。抽查任意 10 秒，要说得出这段画面的任务。核对母题出现次数在 4–6 次、状态至少变一次。确认没有一句歌词因为背景太花而读不清。
