# 《宿敌》水墨 MV · 创作说明

## 一句话

**一个万敌不侵的人，一生只输给一个人。** 命运让她成了他的宿敌：雷雨夜的青石桥上，他一掌击中了那个乔装的人——是她。从此他带着她留下的朱砂小兽，借她的孤单，用一生去还。

## 歌曲怎么读

- 歌词最贴近萧峰与阿朱：恩怨各一半、灯笼血红染、寻仇已太晚、天上星（阿朱金锁片「天上星，亮晶晶，永灿烂，长安宁」）、长安（长久安宁）、绝笔、借你的孤单今生难还。
- 题眼是一个反转：**宿敌是谁？** 读者说「原来，你才是我命中的宿敌呀」。最强的人只败给最轻的东西——一片花瓣、一个人。
- 不点原著人物名：画面只用写意人形，熟悉原著的人能认出杏子林、青石桥、雁门关、金锁片、塞外牛羊之约；不熟悉的人也能看懂一个完整的爱情悲剧。

## 结构：闪前 + 三遍副歌递进

| 段落 | 时间 | 画面任务 |
|---|---|---|
| 前奏 | 0–22.6 | **黄金三秒**：满屏浓墨的雨夜，闪电「揭」开 6 帧——桥上一掌、斗笠飞起；第二道闪电里桥头一点朱红（Clawd 睁大眼）。雨把墨冲掉，写出片名「宿敌」，落印。挂轴竖摇：星河 → 远山关隘 → 石拱桥 → 杏花下睡着的 Clawd（全片母题一次交代） |
| 主歌一「相遇」 | 22.6–62.2 | Clawd 醒来跑向她；一条花瓣的线从她飘向林外的他；刀剑围住他，他一震，刀剑化墨点，墨点落成杏花逐朵开（每个字开一朵）；长卷四季同行；雨中大氅遮雨；一片花瓣落进他掌心——「除了你万敌不侵」 |
| 副歌一「恩怨」 | 62.2–101.8 | 圆相（一半浓一半淡）→ 灯笼渗墨、他赶到时已太晚 → 月下门童叹气，墨晕里是「昨夜」 → 星河命盘「定盘」 → 她写下绝笔「遇君已是长安」，闪电切到雨中赶来的他 → 她摸摸睡在信上的 Clawd，乔装走进雨里 |
| 间奏「青石桥」 | 101.8–124.1 | 兑现开头的闪前：桥两端两个人 → **全片第一次真静默**（只剩雨，最后一滴水）→ 一掌化龙 → 斗笠飞起，大氅化墨，是她 → 他抱住她，Clawd 跑来 → 金锁落进他掌心，她的手垂下 → 雨把一切冲成纸白 |
| 主歌二「孤岛」 | 124.1–163.8 | 孤岛雪雨，雪落满肩，Clawd 举手接雪（徒劳的小动作）→ Clawd 踩水捞起海上的星，放进他掌心 → 竖摇下沉到深谷孤坟 → 金锁上的字一笔笔显出，她的笑在墨晕里一闪 → 手指按进墨里，墨洇成江湖 → 江湖缩进星河命盘 |
| 副歌二「失去」 | 163.8–203.4 | 同一组构图，换了意思：圆的两半是两支军队 → 两岸营火的灯笼 → 门童换成 **Clawd**，墨晕里是没实现的塞外牛羊之约 → 星从他掌心升进命盘 → 他写下「长安」，两军扑来 → 他折断一支箭，两军停住，他走进白雾 |
| 停顿 | 203.4–205.9 | **第二次真静默**：空崖、断箭、Clawd，一片雪落下 |
| 副歌三「星河」 | 205.9–245.5 | Clawd 绕着断箭走出一圈脚印（圆相的回声）→ 万盏天灯 → 门后亮起光，他们向 Clawd 招手 → 两颗星并排嵌进命盘 → **倒放**：龙回掌心，她从桥面站起，宿敌来犯，这一次是拥抱 → 两人沿星河走上天 |
| 尾奏「钤印」 | 245.5–263.3 | 画面蒸发成纸，只剩两颗星和 Clawd；Clawd 一跳落下，留下朱红白文印「长安」；题跋「天上星 亮晶晶 永灿烂 长安宁」 |

三遍副歌的六个母题构图（圆相、灯笼、门与月、星河命盘、绝笔、诀别）每次回来都换了人、换了意思，这是整支 MV 的骨架。

## Clawd：唯一的颜色

水墨只允许一种朱红：印章 + 故事里一个很小的强调物。这个强调物就是 Claude 的小宠物 Clawd。它先是她的宠物（远景里一点红就能找到她），她死后跟着他（**红色从她身边移到他身边**），三遍副歌里替代门童守门，最后自己落成一方印。片头的印和片尾的印是全片的首尾呼应。

## 转场

全片没有叠化和划像，只用水墨本体的转场，每个都有画面里的起因：
- **墨晕**：下一场在扩散的墨里长出来（花瓣落掌 → 圆相；月亮 → 命盘；金锁 → 她的笑；手指按墨 → 江湖）。
- **雾带横移**：时间跳转（片名 → 星河、相遇 → 长卷、门 → 月）。
- **雨水冲刷**：雨来了，或雨把一切冲走（圆相的浓墨一半淌成夜色；桥上之后冲成纸白）。
- **闪电切**：只用在「宿敌已来犯」，白光的峰值上换镜。
- **回忆气泡**：门童、Clawd 叹气之后，「昨夜」在一个墨晕圈里出现又干掉。

## 节奏与声音

- 速度 96.9 BPM，网格与原曲一致。主歌 5 秒一个画面任务，副歌 2.5 秒一个变化点；间奏先极慢（3 秒静止）再极快（一掌 6 帧）。
- 两处真静默：间奏出掌前、末段副歌前。静默之后的第一个声音是全片最重的（出掌的鼓与扫弦；末段副歌的第一拍）。
- 每个看得见的动作都有声音：笔声、印声、水滴、刀光、墨龙、折箭、花开（每朵一个音）。

## 卡拉 OK 字幕

- 思源宋体 Light（细体），60 px；KTV 双槽错落（上句靠左、下句右移），一句唱完它的槽就留给下下句。
- 逐字着墨：亮的画面里淡墨 → 焦墨，夜里淡纸色 → 亮纸白；每个字内部平滑推进，比字的开唱提前 40 ms。
- 前奏、间奏、停顿之后的第一句，开唱前四拍有四个倒计时点。
- 每行开头一枚小朱印（水墨风格的题跋规矩），位置跟着每个镜头的留白走，不压人物和 Clawd。
- 时间来自原曲的逐字时间轴，所以换上原曲音频就是标准的卡拉 OK MV。
