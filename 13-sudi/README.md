## 关于音乐与对齐（重要）

原曲录音有版权，不放进仓库，所以 **`sudi.mp4` 是无音轨的纯画面 + 卡拉 OK 歌词**。它的第 0 帧就是原曲的 0:00：把原曲放到 0:00 就对上了。

画面与字幕按原曲（263 秒录音室版）的**逐字时间轴**对齐：
- 逐字时间来自公开的 KRC 卡拉 OK 歌词（52 句 316 字，毫秒级），并与网易云的逐句时间戳交叉核对：52 句文字完全一致，每句开唱时间相差都小于 0.7 秒，且没有越往后越大的漂移（网易的时间戳习惯提前约 0.3 秒显示）。
- 关键画面卡在具体的字上：圆相在「揽」合上、灯笼从「染」开始渗墨、门童在「叹」叹气、命盘在「盘」锁定、绝笔在「干」墨干、闪电切在「宿敌已来犯」的「宿」、一掌化龙在间奏第 44 小节的重拍（109.27 s）。
- 自查：第一句「会在何处见到你」的「会」在 **0:22.54** 开始着墨。
- **已用原曲音频验证**（`docs/原曲对齐验证.md`）：Whisper 从原曲人声里独立识别出的 174 个字，与本片时间轴的差中位数 −0.04 秒，全曲无漂移；原曲速度 96.97 BPM，与本片网格（96.90）的小节起点相差 0.02–0.16 秒。结论：第 0 帧 = 原曲 0:00，不需要偏移。

想直接得到带原曲的成片，一条命令（不重渲画面，几十秒）：

```sh
sh sudi-shuimo/with_song.sh /path/to/天龙八部之宿敌.mp3      # 第二个参数可微调整体偏移（秒，正数 = 原曲推后）
```

如果你的音频开头多/少了一段静音，画面会整体差一个固定值，用这个偏移参数（或在剪辑软件里挪音轨）修正即可。

## 从源码重建

需要 Node 20+、ffmpeg、Python 3.11+，以及 Lemo-Opuscar 库（放在 `~/lemo-opuscar`，按其 README 安装依赖）。`music/score.py` 是一份未完成的原创配乐草稿，成片不使用。

```sh
sh sudi-shuimo/build.sh      # 歌词时间轴 → 事件 → 逐帧渲染 → 歌词层 → 叠加 → 交付编码
```

没有 GPU 的机器上逐帧渲染约 45 分钟（WebGL 走软件渲染）。
