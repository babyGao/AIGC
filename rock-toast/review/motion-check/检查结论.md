# 动态卡顿检查

根因：笔触在移动，底图仍在原位置叠化，新补的笔触直接出现在终点；同一物体的各层没有一起连续运动。慢放又放大了残影与停滞感。

影响范围：9 个动态镜头共用这套处理，残影风险贯穿主要动作段，应统一修复动态合成，不能只处理落盘一处。

| 核对项 | 结果 |
|---|---|
| 成片 | 40.30 秒、60 帧/秒，2418 帧时间戳连续 |
| 15 个镜头 | 镜头内相邻帧均不完全重复 |
| 落蛋 | 5 张原片画面铺满 1.36 秒，约 10.2 倍慢放 |
| 淋奶油酱 | 17 张铺满 2.73 秒，约 5.1 倍慢放 |
| 面包落下 | 成片约 18.67 秒，旧位置残影在下一帧突然消失 |
| 糖浆细线 | 开头和末次淋汁均固定绘制，未随液体运动 |

所以，继续增加笔触精细度或输出帧率不能消除这些问题，应先统一物体的运动。

对照 lemo：油画渲染器文件完全相同；示例先按时间计算动作，再以固定随机种子绘制，静止颜料保持稳定。

建议：让底色、轮廓、笔触和高光共同跟随主体；正确清除旧位置并处理遮挡；缩减过度慢放，或为蛋液、糖浆补连续动作。

证据：[落下面包的连续帧](s09-boundary.jpg)、[落蛋全过程](s04-action.jpg)、[检查数据](metrics.json)。相邻帧变化量仅辅助定位，不代表动作自然度评分。
