# 巨石吐司 · 油画厚涂版方案

**目标**：原片的菜和工序不变，用代码从原片逐帧重画成油画厚涂，做出米其林级别的观感。手、手套、真人、刻度、烧字都在下笔时画掉，不先修图再画。新画约 20%：暗场背景、炭灰石盘、轮廓光、高光、点缀、片名。

**规格**：竖屏 1080×1920，60 帧/秒，40.2 秒，88 拍/分。原片是 30 帧，慢放后几帧才有一张新原片；新原片带来的补笔、褪笔、换色都分摊到中间每一帧里完成，所以画面不会一顿一顿。中文旁白，画面上加字幕。

## 一、画法

| 层 | 来源 | 做法 |
|---|---|---|
| 背景 | 新画 | 近黑暖炭色暗场，主体后方一团暖光，远处几颗焦外光斑；台面是深胡桃色，带一道反光 |
| 主体 | 原片逐帧 | 刮刀笔触由粗到细下笔（细档：最大笔半径 32 像素、最小 2.8 像素），颜色取自原片。白瓷换成炭灰石盘，量杯画成水晶杯。左后上方主光加暖色轮廓光，盘子上加接触阴影 |
| 杂物 | 原片里有，画里没有 | 标成"不取色"区域，由同一物体周围的颜料盖住 |
| 动态 | 原片光流（平滑过、静止处归零）；勺、刀、叉、下落的面包按整体变换跟踪 | 笔触随画面移动，会动的物体上的笔触整体平移旋转；物体离开，笔触在这一段里逐帧褪掉；新露出来的地方提前算好、逐帧淡入；颜色逐帧向下一张原片过渡 |
| 收尾提白 | 原片高光 | 果酱反光、糖浆、油光处点厚颜料 |

## 三、文案（四层结构）

| 层 | 旁白 |
|---|---|
| 冲击开场（男声） | 热量炸弹！巨石强森的放纵餐。 |
| 钩子＋场景 | 这一口，是强森留给自己的放纵。 |
| 原料溯源 | 四英寸厚的吐司，／一百毫升牛奶，两颗鸡蛋，一勺肉桂。 |
| 工艺叙事 | 每一面，都喝饱蛋液。／翻一次面，焦香就深一层。 |
| 感官词典 | 花生奶油酱，顺着边缘慢慢垂下；蓝莓果酱，整勺落下；最后，一线枫糖。／一叉下去，外脆，里软，蛋奶香冒出来。 |
| 场景锚定 | 热量很高，可练完腿的周日早上，就该有这一口。／巨石吐司。 |

片名：巨石吐司 · THE ROCK TOAST · 四英寸 · 三重淋 · 一口放纵。

## 四、声音

| 层 | 做法 |
|---|---|
| 配乐 | 原创，降 E 大调。竖琴琶音、颤音琴、大提琴拨奏和长音、钟琴。备料段每个动作配一个音，淋酱段奏主旋律 |
| 拟音 | 程序合成：刀切面包皮、倒奶、蛋黄落下、搅拌、淋蛋液、油煎、落盘、三次淋酱、叉子压破外壳、片名扫光 |
| 静默 | 第 37 拍整拍静默，之后的第一个声音是叉子压下去 |
| 旁白 | 微软神经语音晓晓，语速放慢；配乐在旁白下压低约 9 分贝 |

说明：开场人物是原创的熔岩岩石巨人（借"巨石"外号），不画真人肖像；之后各镜时间整体顺延 2.73 秒。
