# 米其林设计规则：「雕光静物」

**一句话**：暗场里只有一道菜在发光。用光把它的每种材质"雕"出来（玻璃质感），颜色只留给食物（油画厚涂），用前中后三层把它托成一个小舞台（纸片立体书）；镜头永远缓慢靠近，工序快、高潮慢。

来源：三种风格的共性（`三风格共性.md`）和 5 条参考片的逐帧分析（`refs/参考片分析.md`）。

## 一、画面

| 维度 | 规则 | 数值 |
|---|---|---|
| 明暗 | 低调暗场，背景接近黑；只有食物和它的反光是亮的 | 平均亮度 0.25–0.35；背景亮度 < 0.08 |
| 布光 | 后侧轮廓光勾出外形（白边）＋低角度掠射光显纹理＋一盏暖色主光；不用正面平光 | 轮廓光强度约为主光的 1.5 倍；掠射光与台面夹角 10–20° |
| 色彩 | 背景和餐具中性（炭灰、深胡桃木）；最纯的颜色只给食物；暖光冷影 | 背景饱和 < 0.15；主体饱和 0.6–0.8 |
| 主色族 | 每一段一个主色族，段落切换即换色 | 蛋液段金黄；煎段焦糖橙；淋酱段象牙、紫、琥珀 |
| 空间 | 前景虚化道具／中景主角在焦平面／后景暗色加光斑；竖立元素当背板 | 景深浅：焦外虚化半径 ≥ 12 像素（1080 宽） |
| 构图 | 主角占画面高度 1/3 以上；居中或落在三分线；四周大量负空间 | 宽景里不被画框裁切 |
| 细节 | 每种材质对应一种光：糖浆透光、酱汁高光、面包孔隙、肉桂颗粒、焦糖斑、油泡 | 放大到 100% 仍有纹理 |
| 摆盘 | 稠酱先定结构；点酱用奇数、由大到小；配料和酱线成夹角；至少一个竖立元素 | 点酱 3 或 5 个 |

## 二、动态

| 维度 | 规则 | 数值 |
|---|---|---|
| 运镜 | 默认缓推近；沿食物表面横向滑移；收尾拉远看全貌；从不手持，也不完全锁死 | 每镜放大 1.07–1.2 倍；开场或揭示可推到约 2 倍 |
| 节奏 | 工序段快剪，高潮和成品慢放，中间至少一次明显的减速 | 工序 0.8–1.5 秒一镜；高潮 2.5–4 秒；全片中位约 1.3 秒 |
| 液体 | 细流从画框外进入 → 落点特写 → 顺边缘下挂，下挂放慢 | 下挂段 0.5 倍速感 |
| 剖面 | 高潮是"切开看里面"，切面占画面一半以上 | 停留 ≥ 2.5 秒 |
| 开场 | 前 3 秒必须是全片最诱人的画面，不给片头标志 | 0.5 秒内出现运动 |
| 转场 | 只在拍点切；用介质本身转场：淋汁划过、蒸汽遮挡、扫光过黑、黑场呼吸 | 黑场 0.6–0.8 秒；不用叠化 |
| 物体运动 | 只有食物在动，背景不动；每个动作有预备、动作、余韵；不出现手 | 关键落位在强拍 |

## 三、声音

| 层 | 规则 |
|---|---|
| 音乐 | 原声手工质感：拨弦、钢片琴、大提琴、轻打击；慢速温暖，约 84–90 拍/分 |
| 拟音 | 跟材质走：刀切面包皮、牛奶入杯、蛋落、搅拌、油响、酱滴、瓷器轻碰 |
| 静默 | 高潮前一拍真静默，之后第一个声音是全片最重要的声音（叉子压下去） |
| 旁白 | 少而短，低声、慢，像侍酒师介绍菜品；音乐在旁白下压低约 9 分贝 |

## 四、禁止

手和手套；手持晃动；量杯刻度、品牌字样、灶台瓷砖；画面里烧进去的大字；叠化；整片一个速度；白底平光；真人肖像。

## 五、落到巨石吐司

| 原片元素 | 米其林化 |
|---|---|
| 白盘白碗 | 炭灰哑光石盘、深色碗，衬出金黄和紫 |
| 量杯 | 无刻度的水晶杯，掠射光下杯壁有一圈高光 |
| 手拿面包、戴手套翻面 | 物体自己动：面包缓缓落进蛋液、自己翻面 |
| 燃气灶 | 纯黑背景里一圈暖橙火光，油面有气泡和热浪 |
| 随手淋酱 | 三次淋酱各给一个慢镜头：象牙奶油酱顺边下挂、蓝莓果酱整颗滚落、枫糖浆一根细线 |
| 手写标题 | 细衬线字体的菜名卡，随扫光亮起 |
| 真人试吃 | 删除，换成叉子切开的剖面慢镜头和成品全景 |
