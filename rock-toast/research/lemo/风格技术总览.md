# Lemo-Opuscar 51 种风格：技术总览

**为什么能有这么多手绘风格**：库里的每个画风 = 一套"笔 / 刀 / 墨"的模拟 + 一套"纸 / 版 / 幕"的材料合成。画什么由形状给出，怎么画由引擎决定，所以同一个形状换一套引擎就换一种手绘风格。全部是代码实时画出来的，没有 AI 生成，也没有素材贴图。

## 一、手绘感从哪来（所有手绘引擎共用的五个部件）

| 部件 | 做法 | 用在哪些风格 |
|---|---|---|
| 笔触 | 一笔 = 中心线 + 起笔重收笔轻的粗细变化 + 几十根"笔毛"各自断墨（飞白） | 水墨、水彩、蜡笔、一笔画、钢笔淡彩 |
| 线条抖动 | 每 2 帧换一次噪声种子，线条像手绘动画那样轻轻颤动 | 蜡笔、所有卡通、默片排线 |
| 材料合成 | 显卡着色器模拟纸纹（蜡只粘在纸的凸起上）、墨晕开积边、套色错位、网点 | 蜡笔、水墨、孔版、木刻、浮世绘、丝印 |
| 按笔顺出现 | 每一笔记下"第几秒画到"，画面能一笔一笔长出来 | 钢笔淡彩、铜版画、白板、木刻、水墨 |
| 确定性 | 同样的种子永远画出同样的笔触，任意一帧都能单独渲染 | 全部 |

## 二、51 种风格按画法分五类

| 类别 | 画法 | 风格 |
|---|---|---|
| 程序笔触 + 纸面合成（18 种） | 2D 画布画笔触，显卡合成纸、墨、版的质感 | 蜡笔、水彩、水墨、油画厚涂、一笔画、白板、钢笔淡彩、铜版画、木刻、浮世绘、丝印海报、孔版印刷、半调案卷、红色剪纸、皮影、彩色玻璃、间谍片头、装饰艺术 |
| 2D 矢量卡通（7 种） | 自管坐标变换保证线宽恒定，平涂加硬边阴影，线条抖动 | 橡皮管、80 年代赛璐璐、科幻情景喜剧、50s 扁平、微游戏、综艺节奏、数据叙事（铅笔） |
| 3D 渲染 + 物理后期（11 种） | three.js 建模，物理景深、环境光遮蔽、辉光 | 玻璃质感、积木、纸片立体书、纸雕灯影、移轴微缩、低多边形、HD-2D、后室、产品拆解、白模投影、数据实物化 |
| 真实影像 / 数据驱动（6 种） | 读真实卫星图、显微扫描、档案照片、激光点云，再标注 | 卫星简报、显微叙事、档案灯台、点云测绘、工程简报板、白模投影 |
| 像素 / 字符 / 排版（9 种） | 低分辨率索引色、字符网格、网格排版 | 像素 RPG、ASCII 终端、瑞士排版、象形图形、暗色发布、等距信息图、全息界面、录屏、蓝图 |

（白模投影同时属于 3D 和真实数据两类。）

所以：我第一版把吐司做成 3D 建模，走的是第三类的路子，用来画食物最吃亏。手绘类引擎画的是"笔触"，不追求照片级的写实，正好绕开了这个短板。
