# 参考片分析（5 条，只学语法）

每条都跑了自动分镜：切镜头、估运镜、取主色，帧条在各自的 `shots/stack_*.jpg`。

## 一、数据对比

| 参考片 | 镜数 | 中位镜长 | 主要运镜（按时长） | 平均亮度 | 饱和 | 学什么 |

结论：越"高级"的片子越暗、主体和背景的饱和度差越大、镜头越少锁死。原片亮、平、手持多，正好三项都反着来。

## 二、动态手法（逐条看帧条得出）

| 手法 | 在哪看到 | 具体做法 |
|---|---|---|
| 开场钩子 | 02 开头、02 第 60 镜 | 纯黑底上，食材一个个出现、悬停，然后一起坠落；配一次猛推近（约 2 倍） |
| 结果先行 | 01、原片 | 先给成品或高潮，再回头讲工序 |
| 缓推近 | 02 几乎每镜 | 每镜放大 1.07–1.2 倍，速度均匀，落在食物表面纹理上 |
| 贴面滑移 | 02 第 13、57 镜 | 镜头低角度沿着食物表面横移，像在抚摸纹理 |
| 淋汁 | 01 刷釉、02 第 9 镜、原片 | 细流从画框外进入 → 落点特写 → 顺边缘下挂，下挂段放慢 |
| 滴落 | 02 第 11 镜 | 汁水从食物底边一滴滴垂下，背景纯黑，滴子逆光发亮 |
| 剖面揭示 | 01 惠灵顿、牛肉切片；02 第 17、57 镜 | 每道菜的高潮都是"切开看里面"，切面占画面一半以上，停 2–4 秒 |
| 黑场呼吸 | 02 第 19、41 镜 | 段落之间插 0.7–0.8 秒纯黑，下一段从暗处亮起 |
| 甩镜转场 | 02 第 58–59 镜 | 横向运动模糊带出下一镜 |
| 成品收尾 | 02 第 18、59 镜 | 拉远成全景，打菜名，几秒后整体压暗 |
| 节奏 | 01、02 | 工序段 0.6–1.2 秒一镜快剪；高潮和成品 2.5–4 秒慢放 |

## 三、摆盘与构图

| 规律 | 来源 | 做法 |
|---|---|---|
| 酱汁先定结构 | 05 | 先画一道波浪或一抹，两侧挤三个由大到小的点，主角压在交点上 |
| 渐变与奇数 | 03、05 | 点酱用三或五个、由大到小；彗星拖尾、同心圆、梳齿纹都是常用图形 |
| 酱当堤坝 | 05 | 稠的酱围出边界，稀的汁淋在里面不乱流 |
| 夹角 | 05 | 配菜和酱线成一个夹角，既对称又有层次 |
| 留白 | 04 | 大盘小食，主体只占盘面中心三分之一 |
| 深色哑光盘 | 04、05 | 炭灰或古铜色盘，让橙、黄、紫更跳 |
| 高度 | 01、04 | 至少一个竖立元素，让盘面有立体感 |
