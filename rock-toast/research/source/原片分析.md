# 原片分析：巨石吐司（1.mp4）

44.2 秒，竖屏 720×1280，30 帧/秒，中文旁白，配乐约 82 拍/分。共 21 个镜头，平均 2.1 秒一镜，几乎全是手机俯拍加手持。逐镜帧条在 `shots/stack_*.jpg`。

## 一、结构

| 段落 | 时间 | 镜头 | 画面 | 二创处理 |
|---|---|---|---|---|
| 钩子 | 0–3.8 秒 | 1–2 | 成品吐司，蓝莓酱下挂，顶上一根糖浆细线；真人抠像，手写标题"THE ROCK TOAST" | **保留成品和糖浆线**，删掉真人，标题重做 |
| 真人试吃 | 3.8–9.6 秒 | 3–4 | 明星在户外自拍试吃 | **整段删除**（不画真人），换成菜品镜头 |
| 食欲镜头 | 9.6–14 秒 | 5–6 | 叉子切开，蓝莓果酱从断面涌出 | 保留切开的动作，去掉手 |
| 切面包 | 14–16 秒 | 7 | 面包刀把整块厚吐司一切为二 | 保留，刀自己切，不出现手 |
| 调蛋液 | 16–22 秒 | 8–9 | 量杯里倒 100 毫升牛奶，打 2 个蛋，加 1 勺肉桂粉，搅匀 | 保留，量杯换成无刻度的水晶杯 |
| 浸蛋液 | 22–26 秒 | 10–12 | 吐司放进白碗，淋蛋液，翻面裹满（戴黑手套） | 保留淋蛋液，删手套 |
| 煎 | 26–29.4 秒 | 13–15 | 铸铁锅里四面煎出焦糖色斑 | 保留，加油泡和热气；删灶台 |
| 装盘淋酱 | 29.4–35.5 秒 | 16–18 | 一块平放、一块竖立当靠背；依次淋花生奶油酱、蓝莓果酱、枫糖浆 | **重点镜头**，三次淋酱各给一个特写 |
| 收尾 | 35.5–39.9 秒 | 19–20 | 叉子切开，酱汁漫开 | 保留，做成慢动作 |
| 真人收尾 | 39.9–44.2 秒 | 21 | 明星说"世界上最棒的法式吐司" | **删除**，换成成品定格加菜名 |

所以：真正的制作过程约 26 秒（14–39.9 秒），前后两段真人共约 10 秒，要换成菜品镜头。

## 二、保留的元素（菜品与步骤不变）

| 类别 | 元素 |
|---|---|
| 主料 | 约四英寸厚的布里欧修吐司，顶面金黄发亮 |
| 蛋液 | 100 毫升牛奶、2 个鸡蛋（橙黄蛋黄）、1 勺肉桂粉，搅成带肉桂点的金黄蛋液 |
| 器具 | 面包刀、透明量杯、搅拌叉、白碗、铸铁平底锅、浅色餐盘、深色木底座 |
| 熟的样子 | 四面焦糖色"豹纹"斑，边缘深棕，内部浅黄 |
| 摆盘 | 一块平放，一块竖立当靠背（像沙发） |
| 三种淋酱 | 象牙色花生奶油酱（顺边缘下挂）、深紫蓝莓果酱（整颗果粒）、琥珀色枫糖浆（一根细线） |
| 高潮 | 叉子压开，果酱和奶油从断面涌出、在盘里漫开 |

## 三、要删掉的杂乱元素

| 杂乱元素 | 出现位置 | 处理 |
|---|---|---|
| 真人明星画面、抠像贴纸 | 镜 1–4、21 | 删 |
| 裸手、黑色丁腈手套 | 镜 5–7、10、12–16、19–20 | 删；物体自己动，像有隐形的手 |
| 量杯上的红色刻度字 | 镜 8–9 | 换成干净的水晶杯 |
| 燃气灶、白瓷砖墙 | 镜 13–15 | 换成暗色背景，只留火光和热气 |
| 前景虚焦的手指、叉子把手 | 镜 5–6、19–20 | 删 |
| 画面里烧进去的大字和字幕 | 全片 | 删；字幕改成米其林式细字 |
| 桌上多余的鸡蛋、调料盒、背景胡椒磨 | 镜 7–9 | 胡椒磨做成远景虚化光斑，其余删 |
| 手持抖动、随意构图 | 几乎全片 | 改成稳定的推、移、环绕 |

## 四、色彩

| 色 | 原片取样 | 作用 |
|---|---|---|
| 深木棕 | #58311f、#60342c | 底座和环境，压暗 |
| 奶油白 | #e3d9d1 | 餐盘、奶油酱 |
| 焦糖金 | #9e6633、#af7e22 | 煎好的外皮 |
| 蛋液黄 | #edcc50、#e8c654 | 蛋液段的主色，全片最亮最纯 |
| 蓝莓紫黑 | #201015 | 果酱，最深的点缀色 |

原片的问题：亮度平均（0.5–0.65），反差弱，白盘白碗抢了视线，主色不够集中。

## 五、黄金三秒

原片靠"明星 + 成品 + 糖浆线"三个元素抓人。二创去掉明星后，钩子必须完全靠食物本身：**用微距拍糖浆细线落在焦糖外皮上、果酱慢慢下挂**，再接菜名。

## 六、旁白要点（只保留事实，措辞重写）

巨石强森最爱的法式吐司；四英寸厚；100 毫升牛奶、两个鸡蛋、一勺肉桂粉；每一面都裹满蛋液；不断翻面煎出焦褐色；灵魂是最后的花生奶油酱、蓝莓果酱和枫糖浆；热量很高，满足感也拉满。
